TELECOM NETWORK OPERATIONS ASSISTANT
RAG INDEXING — IMPLEMENTATION SUMMARY
============================================================

1. DATASET
- Dataset: Telecom network incident data
- Total records: 100,000 incidents
- One row = one network incident
- Unique identifier: Incident_ID
- RAG intermediate format: JSONL
- JSONL file: incident_documents.jsonl

2. JSONL DOCUMENT STRUCTURE
Each incident contains:
- id: Incident_ID
- text: Natural-language description used for semantic embedding
- metadata: Structured incident values used for filtering/reference

The semantic text includes network performance, operational,
environmental, security, location, issue, and fault information.

3. EMBEDDING MODEL
- Model: BAAI/bge-small-en-v1.5
- Framework: SentenceTransformers
- Embedding dimension: 384
- Embedding generation: Local
- Normalization: Enabled
- API dependency: None

Reason for local model:
- OpenRouter embedding was initially tested.
- OpenRouter generated 2048-dimensional embeddings.
- Full 100K indexing encountered HTTP 429 rate limiting.
- The project was therefore switched to local BGE-small embeddings.

4. CHROMADB
- Vector database: ChromaDB
- Collection: telecom_incidents
- Persistence path: ./chroma_db
- PersistentClient: Yes

Each ChromaDB record stores:
- Incident ID
- Original incident document text
- 384-dimensional embedding
- Structured metadata

5. INDEXING CONFIGURATION
- Total records: 100,000
- ChromaDB batch size: 128
- Embedding batch size: 128
- Total batches: 782

Batch calculation:
- 781 full batches × 128 = 99,968 records
- Final batch = 32 records
- Total = 782 batches

6. INDEXING FLOW
incident_documents.jsonl
        ↓
Read incident records
        ↓
Collect 128 records
        ↓
Generate BGE-small embeddings
        ↓
384-dimensional vectors
        ↓
Upsert into ChromaDB
        ↓
Repeat until all 100,000 records are indexed

7. PROJECT FILES
- incident_documents.jsonl
  Contains the 100K RAG documents and metadata.

- embedding_model.py
  Loads BAAI/bge-small-en-v1.5 and generates embeddings.

- chromadb_setup.py
  Creates/opens the persistent ChromaDB collection.

- index.py
  Reads JSONL, generates embeddings in batches, and indexes
  the documents into ChromaDB.
